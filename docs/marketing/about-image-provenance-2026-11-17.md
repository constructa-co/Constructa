## Snag

The About page (both launch profiles, `src/components/marketing/cohort-about.tsx` and `src/components/marketing/full-about.tsx`) used two illustrations with unknown rights:

- `public/images/minimalist infographic cluster of small construction buildings.png` (built-by panel)
- `public/images/spreadsheet grid and warning & error symbols.png` (problem panel)

Both entered the repo in a single bulk upload, commit `eedf67c` ("Fix UI styling, server actions boundary, and configuration"), with no licence, origin, attribution or generation record. D51's CON-046 fix had reused them as "existing committed non-people assets"; #191 re-examined the rights question.

## Licence verification result: not verifiable

Searched committed evidence for any free-licence or origin record for these two files:

- `git log --follow` on both files: only commit `eedf67c`, no message detail.
- `docs/` search for provenance/licence/source references: nothing. The closest records are `docs/delivery/2026-11-12/kimi-a074-cover-photo-inventory-decision.md` (inventories the repo images but explicitly states "Image sourcing and AI generation are **not activated** — no external assets were fetched and nothing was generated", i.e. it records no licence) and `docs/temp-files/marketing-public-image-sweep-2026-11-15.md` (a broken-link sweep only).
- The same bulk upload contains other files the repo itself labels AI-generated (garbled-text mock-ups and AI people images), so "AI-generated by an unknown tool/service, rights unconfirmed" is the most plausible origin — and that is not a free licence.

No committed evidence verifies a free licence. Per #191, unverified assets cannot stay on About.

- **Built-by panel** — swapped to the owned, verified Constructa capture `docs/evidence/marketing-product-screenshots-2026-11-15/02-programme-saved-stages-1440x900.jpg` (same evidence class #187 shipped, from the 15 Nov 2026 synthetic phase-one fixture run) with the preserved synthetic disclosure: "Saved programme stages in the current review interface · synthetic journey fixture capture from 15 November 2026 · made-up job data · simulated saves."
- **Problem panel** ("The problem we saw") — illustration removed; the panel is text-only. Layout preserved: it now uses the same full-width statement layout as the founder-quote section (`styles.statement` in the cohort profile, `max-w-3xl mx-auto` in the full profile).
- **Solution panel** — unchanged capture (`01-estimate-price-adjustments-1440x900.jpg`) and unchanged disclosure; it now sources from the shared registry below.
- All five unverified files remain on disk (deletes are not permitted) but nothing on About references them.
- All About imagery now resolves through one registry: `src/components/marketing/about-image-provenance.ts` — verified captures (`aboutCaptures`), the removed-unverified blocklist (`removedUnverifiedIllustrations`, with reasons). Width/height props now carry the captures' true pixel dimensions (1440×2367 and 1440×2126 full-page fixtures).
