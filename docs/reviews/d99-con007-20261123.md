# CON-007 Email-link opt-in: static source review (revised)

Commit e3f836b. Static only. Not runtime acceptance, and not closed.

**Source checked:** `review-send-client.tsx`, `sendProposal`/`retryDelivery`, `publishProposalAction` (lines 444–610 shown), and `review-send-email-confirm.test.tsx`.

**Confirmed in source**
- Email is off by default. Opt-in needs a saved address, and Send is disabled until the recipient is confirmed.
- Without opt-in, publish receives `deliverByEmail: false` and no confirmation.
- The server enforces this independently: `deliverByEmail` without `emailRecipientConfirmed === true` is refused before any access or write (line 459). This closes my earlier "controller does not enforce" point.
- The two existing client tests cover the blocked and non-email paths.

**Residual risks (source-only; no production problem inferred)**
1. **Confirmation persists across sends.** `deliverByEmail` and `emailRecipientConfirmed` reset only in the opt-in `onChange`, and nothing resets them on `send/published`.
   - This matters only if `router.refresh()` does not remount the component, which is unseen.
   - In that case, version 2 can email again after only the preview tick.
   - The ticked boxes stay visible, so nothing is hidden, but it is not a fresh per-send confirmation.
2. **Confirmation is not bound to an address.** The client sends a boolean, and the server emails `project.client_email` as read at publish time (line 587). If the saved address changes after confirmation, the confirmed and emailed addresses differ. The content hash might cover this, but the snapshot contents are unseen.

**Owner follow-up (no fix launched):** decide whether per-send reconfirmation is required. Also decide whether the hash or the publish input should carry the confirmed address.

**Evidence limits:** the retry action, server publish tests and `PublishProposalResult` are unseen. The first client test's negative `waitFor` assertion passes immediately. The guard is synchronous and the server also enforces it, so no new test is mandatory.
